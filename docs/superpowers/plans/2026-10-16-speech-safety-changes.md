# STT 안전 처리 및 내부 발화 변화 감지

승인된 범위: Q8 STT 참고 문구 제거, 비음성/비정상 전사의 집계 차단, 속도·음량 변화 감지 구현. 감지 결과는 UI, WebSocket, DB, 리포트, 로그에 노출하지 않는다. 원본 미디어와 전사를 진단 로그에 남기지 않는다. 완료 후 로컬 main에 병합하며 푸시는 별도 요청 전 하지 않는다.

- [x] STT: `stt_context` 설정·IPC·호출 경로 제거. 확정 발화도 실제 에너지/유한성 확인. 문장부호뿐인 결과와 극단적 길이 결과 거절, 짧은 정상 답변·반복 발화 유지.
- [x] 집계: 비어 있거나 거절된 전사는 속도/습관어/대본/속도 감지 기준선에 넣지 않는다. 음량은 전사와 별도로 VAD 유성 프레임에서 측정한다. 거절 사유는 고정 코드만 사용.
- [x] 내부 감지: 기존 VAD 판정을 한 번만 사용. 20ms 프레임의 음량을 500ms 창으로 집계하고 발화 중 입력 레벨만 비교. 속도는 유효 확정 발화 단위. 최근 30초의 중앙값을 기준으로 비교하며 초기 데이터 부족·짧은 변화·무음은 판정 보류.
- [x] 초기 개발용 기준: 음량 6dB/1초 지속, 속도 25%/유효 발화 2초 지속. 음량 기준선 최소 유성 3초와 6창, 속도 최소 유성 6초와 3발화. 현장 튜닝 전 정확도·감정 의미를 보장하지 않는다.
- [x] 감지 결과는 시간 구간·종류·방향·기준값·관찰값만 최대 256개 세션 메모리에 유지. 시작 지연·추가 모델·사용자 피드백 없음.
- [x] 실패 재현 테스트 → 구현 → 전체 Python/Node 검사·빌드 → 합성음성 실제 Q8 검사 → 최종 코드 검토.

기존 작업 기준 커밋 `5c22eda`. 현재 폴더의 `codex/speech-safety-change-detection`에서 작업한다.

검토 보완: 확정된 짧은 답변은 앞뒤 무음으로 희석된 전체 RMS가 아니라 20ms 프레임 에너지를 검사한다. VAD는 다시 실행하지 않는다. 같은 임계값을 넘는 샘플이 최소 `min(100ms, 확정 유성 시간)`만큼 있어야 한다. 100ms·RMS 0.004 음성 + 무음 여백 회귀 테스트에서 수정 전 실패/수정 후 통과.

변화 확인 중에만 기준을 잠시 고정하고 확인 후에는 최근 30초 중앙값을 계속 갱신한다. 35초 넘게 크거나 빠른 상태 유지 후 반대 방향으로 변하는 두 회귀 테스트도 수정 전 실패/수정 후 통과. 재검토에서 두 문제 해결 확인.

실제 Q8 모델: 확정 무음은 추론하지 않으며 합성 잡음·단일 톤의 문장부호 결과는 집계에서 제외. 짧은 답변, 작은 목소리, 무음 여백을 붙인 작은 목소리, 실제 반복, 발표 합성음성 인식 확인. 실제 WebSocket 발표·짧은 답변·무음 및 9B 요약 전후 수명주기도 통과. 원본 테스트 음성은 임시 폴더에서 삭제.

최종 병합 전 검증: Python 271개, Node 41개 통과. Ruff/mypy/ESLint/프로덕션 빌드/diff 검사 통과. 기존 Starlette TestClient/httpx 사용 중단 예정 경고 1종. 실제 마이크 및 CPU/Docker 성능은 미검증이고 감지 임계값은 개발용이다.
