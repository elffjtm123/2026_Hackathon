# 시선 개선 묶음 현장 확인

자동 테스트는 계약·보정·판정 로직 확인이며 실제 사용자 방향 정확도를 입증하지 않습니다.
현재 현장 결과: **사용자 확인 대기**. 카메라 응시와 화면 응시는 구분하지 않습니다.

## 실행 / 모델 준비

기존 `mediapipe==0.10.21`, UniFace/MobileGaze를 재사용합니다. RetinaFace는 기본 실행에서 제외합니다.
공식 Face Landmarker v1 asset만 로컬 `.models/face_landmarker.task`에 준비합니다.
경로는 `FACE_LANDMARKER_PATH`로 지정합니다. `.models`는 Git에서 제외되며 자동 다운로드는 하지 않습니다.

```sh
mkdir -p .models
curl --fail --location https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task --output .models/face_landmarker.task
shasum -a 256 .models/face_landmarker.task
```

SHA256: `64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff` (실행 시 검증).
모델의 라이선스는 공식 모델 카드의 Apache-2.0 안내를 참고합니다.
[Face Landmarker 가이드](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker),
[Face Mesh V2 모델 카드](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20MediaPipe%20Face%20Mesh%20V2.pdf).
Landmarker는 IMAGE/최대 2개 얼굴 모드입니다. 중복 얼굴은 판단 불가이고 자체 EMA로 안정화합니다.
landmark bounds로 얼굴을 잘라 MobileGaze에 전달합니다. Tasks 결과에서 검출 신뢰도를 얻을 수 없어 null로 유지합니다.

## 최초 튜닝 값과 한계

- 좌우는 **사용자 몸 기준**, pitch 양수는 위입니다. 프리뷰는 거울 반전되지만 입력 프레임은 반전되지 않습니다.
- MediaPipe 변환 행렬은 Rz·Ry·Rx 분해 후 yaw=-Ry, pitch=-Rx로 변환합니다. 합성 축 테스트는 통과했으나 실제 축은 아래 현장 체크가 필요합니다.
- 얼굴 면적 비율 0.02, crop 밝기 30–235, Laplacian 분산 40, 양쪽 눈 EAR 0.15가 초기 품질 거절 기준입니다. 안경·조명·눈 형태에 따라 조정해야 하는 휴리스틱이며 정확도 점수가 아닙니다.
- 정면 head yaw/pitch ±15°, 품질 조건을 통과한 연속 8개 이상·0.75초 이상 관찰로 보정합니다. 8fps에서는 약 1초가 필요하며 추론 지연·품질 실패 시 더 걸립니다. 각 축은 중앙값 절대편차의 2배가 4° 이하인지 검사해 드문 추정값 튐을 허용하고, 기준도 중앙값으로 계산합니다. 실제 응시 대상이나 정확도를 입증하는 기준은 아닙니다.
- EMA 250ms, 이탈 진입 12°/복귀 8°, 2초 지속 경고/5초 반복 제한입니다. 1.5초 수신 공백은 판단 불가, 3초 이상 관찰 실패/얼굴·해상도 변경은 다시 보정이 필요합니다.
- 연습 중 ‘다시 보정’은 시선 기준만 재설정합니다. 음성 녹음·연습 시간의 기준은 유지합니다.
- 초기 보정 중 얼굴 위치 변경·관찰 실패는 수집 구간만 비웁니다. 15초 시간 초과 후 자동 완료하지 않으며, 카메라·연결을 유지한 채 ‘다시 보정’으로 재시도할 수 있습니다.
- 얼굴·시선 측정 실패를 긴장/당황/감정으로 해석하지 않습니다.

## 사용자 확인 (각 항목 결과는 나중에 입력)

밝은 곳에서 시작을 누르고 얼굴을 정면으로 유지한 채 카메라를 바라봅니다.
진단 영역에서 얼굴 각도와 시선 각도·품질 플래그를 따로 확인할 수 있습니다.
각 방향은 2–3초 유지하며 사용자 몸 기준 좌우와 화면 표시를 비교합니다.

| 동작 | 확인할 표시 | 현장 결과 |
| --- | --- | --- |
| 정면 보정 | 안정 구간 뒤 완료, 연습 타이머 시작 | 기존 16회/1.5초 설정: 밝은 곳에서 5/16 정체·시간 초과 (사용자 보고). 8회/0.75초 수정 후 재확인 필요 |
| 얼굴 고정·눈만 좌/우/상/하 | 얼굴 방향은 정면, 시선 방향만 해당 방향 | 미확인 |
| 눈 중앙·얼굴만 좌/우/상/하 | 얼굴 방향 변화가 시선 값과 별도로 표시 | 미확인 |
| 옆 얼굴로 시작 | 보정 진행 누적 안 됨·정면 안내 | 미확인 |
| 눈 감기·안경·어두운 곳 | 판단 불가 또는 품질 안내, 좋은 상태로 위장 안 함 | 미확인 |
| 얼굴 밖으로 이동 후 3초 이상 | 판단 불가·다시 보정 필요 | 미확인 |
| 다시 보정 | 원래 연습 타이머/음성을 유지하며 기준만 갱신 | 미확인 |
| 종료·다시 시작 | 이전 기준·관찰값 혼입 없음 | 미확인 |

실패 시 동작·표시 문구·진단 각도·품질 플래그만 기록합니다. 사용자 영상 저장은 필요하지 않습니다.

## 개발 검증 기록

공식 공개 portrait.jpg smoke에서 단일 얼굴·두 종류 각도·품질 측정값을 확인했습니다.
첫 추론 33ms는 단일 공개 이미지의 실행 확인일 뿐 사용자 정확도나 지속 처리 성능의 측정이 아닙니다.
실제 사용자 카메라·마이크는 개발 자동 검증에 사용하지 않았습니다.
