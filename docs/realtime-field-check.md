# 최종 기능 확인 (정성평가 보류)

대상: Mac localhost 단일 사용자, 실제 Qwen3-ASR·MediaPipe/MobileGaze. CPU 최적화·감정 추론·면접 질문 생성은 제외.

## 구현된 경로

PCM → VAD 발화 → 최종 STT → 동일 발화 ID 기반 속도/습관어/대본 정렬 → 서버 종료 리포트.
WebRTC도 PCM16 mono 16kHz·연속 샘플 시각을 사용하고 리샘플러 잔여 음성을 전달한 뒤 종료한다.
브라우저 기본 경로는 WebSocket이다. 대본 가이드는 시간만으로 전진하지 않는다.
문장 요약 힌트는 수동 메모이며 요약 LLM은 도입하지 않았다.
대본 일치도는 인식 텍스트 비교이지 발음 진단이 아니다. 새 리포트에는 받아쓰기/비교 원문이 저장되지 않는다.

## 정성평가 때 채울 항목

| 항목 | 확인 방법 | 결과 |
|---|---|---|
| 무음·잡음 | 무음 5초와 생활 소음에서 임의 전사/경고 유무 | 추후 작성 |
| 짧은 답변 | 마지막 ‘네’ 직후 종료 후 받아쓰기 확인 | 추후 작성 |
| 반복·습관어 | 동일 문장 두 번 + ‘음/어’ 후보, 서버 누적과 종료 결과 비교 | 추후 작성 |
| 발화 속도 | 느리게/빠르게/긴 쉼, 대기 상태와 경고 확인 | 추후 작성 |
| 대본 정렬 | 무관한 말·반복 구간·띄어쓰기 차이, 실제 진행과 목표 진행 비교 | 추후 작성 |
| 문장 힌트 | 문장 메모 입력, 마지막 단어에서도 메모/문장이 유지되는지 확인 | 추후 작성 |
| 시선 관찰 | 얼굴을 가리거나 영상 지연 시 관찰 범위 감소·미분석 표시 | 추후 작성 |
| 모델 실패 | 오류/미완료 표시와 재시도 안내, 가짜 결과 없는지 확인 | 추후 작성 |

자동 회귀 검증은 로직/계약/저장 정책을 검증한다. 개인별 STT·시선 정확도는 보증하지 않는다.
작은 목소리의 VAD 누락, STT의 습관어 생략, 8초 최대 발화 경계에서 단어 분할 가능성은 정성평가 후 조정한다.

## 2026-10-08 자동/실행 검증 기록

- Python 회귀 145개, Node 화면/통신 34개 통과. Ruff·mypy·ESLint·타입 검사·프로덕션 빌드 통과.
- 실제 캐시 모델 Qwen3-ASR-0.6B(MPS)·MediaPipe/MobileGaze 준비 상태 확인. 새 가중치 다운로드 없이 실행.
- 합성 무음 2초: 전사 없음, 속도·습관어 unavailable, 오류/미완료 없음.
- 합성 한국어 15.026초: 같은 문장 두 번과 최종 ‘네.’ 보존. 67음절/11,460ms, ‘음’ 2회.
- 합성 발표 7.357초: 해당 대본의 최종 정렬 확인, 완료 위치까지 진행, 종료 시각 기준 목표/실제 차이 전달.
- 프론트 localhost:9000 Origin으로 실제 WebSocket 연결 검증. 허용하지 않은 Origin 차단은 자동 회귀에서 검증.
- 임시 DB의 과거 v1 기록 보전·새 기록의 중첩 원문 제거·미완료 저장 확인. 기존 로컬 DB도 백업 후 최신 migration 적용.
- wheel 빌드와 루트 stt.py 없는 격리 import 확인. Docker daemon이 꺼져 있어 컨테이너 실행은 미검증.

위 결과는 처리 경로/계약 검증이다. 합성 입력의 대본 일치도와 진행률을 사람 음성 인식 정확도로 해석하지 않는다.
