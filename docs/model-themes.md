# 전체 서비스 모델 테마 비교

로컬 사이트의 모델 테마 화면(`#themes`)에서 현재 서비스 Q8, Qwen Q8, Whisper Small INT8,
Whisper Base INT8, Korean Zipformer INT8를 선택합니다. 첫 화면(빈 해시)은 현재 서비스 테마의 일반 연습입니다.
선택한 모델은 WebSocket v2 `session.start.stt_model_id`로 서버에 전달되며,
실제 모델 로딩이 성공한 뒤 기존 카메라 보정과 연습을 시작합니다.
실패한 모델을 다른 모델로 대체하거나 예시 전사로 채우지 않습니다.

## 공통 기능

모든 테마는 같은 PracticePage와 SessionPipeline을 사용합니다.
MediaPipe 얼굴 방향, MobileGaze 눈 시선, 기준 보정·재보정,
발표/면접 모드, 대본 가이드, 자막, 발화 속도·필러워드 후처리,
대본/STT 일치도 기반 명료도 추정과 종료 리포트를 유지합니다.
기존 Qwen 어댑터는 재사용하고 후보는 별도 엔진을 로드합니다.
클라이언트 전사 주입이나 Mock 서비스 경로를 추가하지 않습니다.

실시간 연습 후보에도 현재 서비스의 RMS·VAD 검사와 발화 단위 조립을 적용합니다.
Zipformer encoder/joiner는 INT8, decoder는 FP32입니다.
Zipformer의 스트림은 발화마다 초기화하므로 세션 전체의 지속 스트리밍 구조의
최적 성능을 측정하는 실험은 아닙니다.
Qwen Q8은 llama.cpp, Whisper는 faster-whisper, Zipformer는 sherpa-onnx CPU입니다.

## 직접 비교하는 방법

1. 같은 대본·제한시간·발표/면접 모드를 정합니다. 이 세 설정은 같은 탭에서 유지됩니다.
2. 테마 선택 → 시작 → 카메라 보정 → 동일한 순서의 발화/시선 행동을 수행합니다.
3. 종료 후 잔여 음성 처리 완료를 기다립니다.
4. 결과에 정성평가 메모를 남기고 JSON을 저장합니다.
5. 테마 선택으로 돌아가 다른 모델로 반복합니다.

연습·모델 준비·녹음·배치 실험 중에는 테마 이동이 차단됩니다.
서버에서도 한 모델 세션만 허용하며, 다른 탭의 서비스 및 파일 실험과
서로 배타적으로 실행합니다. 로컬 개발용 demo 경로만 모델 선택을 지원합니다.
인증 세션은 기존 정책을 유지합니다.

## 기록 및 지표 해석

종료 기록에는 실제 모델/엔진·스레드·시선 모델·설정과 함께
음성/시선 평균·최대 추론 시간, 관찰 수, 결과 지연, 영상 프레임 교체 수,
최대 오디오 큐 길이와 오류 횟수를 담습니다.
결과 지연은 청크 시작/영상 캡처 상대 시각 기준으로 청크 조립·큐·추론을
포함합니다. 네트워크 왕복이나 브라우저 자막 표시 시간을 의미하지 않습니다.
추론 시간이 제공되지 않은 분석은 임의로 0으로 기록하지 않습니다.

결과와 메모는 이 탭의 sessionStorage에 최신 20개까지 보관합니다.
음성·영상 파일은 저장하지 않지만 전사와 대본 관련 결과는 기록에 포함됩니다.
탭을 닫기 전에 필요한 JSON을 내려받으세요.
저장이 제한되는 환경에서는 결과 원문을 직접 복사할 수 있습니다.

매번 사용자가 다시 발화하고 보정하므로 행동과 입력 차이가 있습니다.
이 결과를 모델만의 인과 효과나 정확도 인증으로 해석하면 안 됩니다.
동일 녹음의 CER/RTF 등 STT 통제 비교는 별도 `#stt-experiments` 화면을 사용합니다.
얼굴·시선 모델은 동일하므로 방향 정확도 자체가 STT 변경으로 개선되는 것은 아닙니다.
명료도는 음향학적 발음 정확도가 아니라 대본/STT 일치도 추정입니다.
현재 서비스의 speech.cpp Q8과 시선 모델은 연습 중 함께 로드되고 종료 시 회수됩니다.
후보 실행 중에도 공통 워커가 함께 있으므로 단독 후보의 최소 RAM 비교가 아닙니다.

## 검증 범위

테스트용 모델 더블을 사용한 단위/프로토콜 테스트는 후보 선택, 공통 음성 후처리,
카메라 보정·관찰 유지, 짧은 음성 잔여 처리, 리포트와 모델 해제의 동작을 검증합니다.
이는 실제 모델의 한국어 인식 품질이나 사용자 시선 방향 정확도를 증명하지 않습니다.
실제 사용자 환경의 정성평가와 반복 실험은 별도로 수행해야 합니다.

2026-10-09 로컬 서버에서 공식 MediaPipe 공개 portrait.jpg와 sherpa-onnx 공개
한국어 음성 test_wavs/0.wav로 다섯 모델 모두 실제 동시 추론을 확인했습니다.
각 세션이 보정을 완료하고 gaze, speech_rate, pronunciation 피드백과
잔여 음성 처리 후 완료 리포트를 생성했습니다. 이 샘플에서 보고된 오류는 없었습니다.
정면 사진 한 장이므로 좌우상하 시선 판정 정확도 검증은 아닙니다.
재실행 도구: `.venv\Scripts\python.exe -m scripts.smoke_live_model_themes`.
다른 연습이나 실험이 진행 중일 때는 실행하지 마세요.
